# 🍅 Помидоры под Минском

Браузерная аркада про огородника: парник, жижа, фитофтора, жара и градус в организме.
Чистый HTML/Canvas/JS — без сборки, без зависимостей, без картинок (вся графика рисуется кодом).

## Суть

Ты — лысый колхозник чуть за 40. Смена — 5 минут. Задача: сдать в ящик **24 спелых
неповреждённых** помидора. Мешает всё сразу:

| Что | Как работает |
|---|---|
| 💩 **Жижа** | поливаешь — куст растёт и завязывает плоды, но влажность в парнике растёт |
| 🦠 **Фитофтора** | споры прилетают из влажного воздуха и через открытые форточки; заражённый куст портит плоды, запущенный — сгорает |
| 💧 **Купорос** | сбивает заразу и даёт иммунитет на 16 сек, но 4 сек после обработки куст трогать нельзя |
| 🪟 **Форточки** | сушат и холодят парник, зато с соседской картошки задувает споры |
| 🥃 **Градус** | это силы. Тратится сам, на жаре — вдвое быстрее. Упал в ноль — ноги не идут. Перебрал — шатает и роняешь |
| ⏳ **Перезрев** | спелый помидор висит недолго: не сорвёшь — упадёт |
| 🦴 **Артрит** | каждые 10 сорванных руки сводит: всё вдвое медленнее, помидоры валятся из рук. Лечится табуреткой или растиркой |
| 🌀 **Радикулит** | прострел при выдирании куста: 15 секунд еле ходишь |
| 🔥 **Изжога** | три стопки без закуски — градус выветривается в 1,7 раза быстрее |
| 🌫️ **Мучнистая роса** | сыро и прохладно — белый налёт, рост встаёт. Купорос и проветривание |
| 🐛 **Колорадский жук** | приходит сам, жуёт листву. Собирается руками (E) или купоросом |
| ⚫ **Вершинная гниль** | пересушил землю — у плодов чернеет донце, это брак |
| 🍀 **Находки** | удачный помидор (идёт за три), чирик (Петрович сгоняет в сельпо), огурец, растирка, верхонки |

Ящик далеко слева, бочка, купорос и НЗ — справа. В руках больше пяти помидоров не унесёшь.
Каждые полминуты что-нибудь случается: печёт солнце, дождь по крыше, сосед копает картошку,
коза Зорька лезет в открытую форточку и жуёт спелый, курица разгребает грядку.

## Колхозный трэш

Мужик приговаривает по ситуации — «Зато своё», «Зато не магазинное», «Эх, помидоры-помидорчики…»,
на жаре «Лысина — это солнечная панель», под градусом «Эт-та не я шатаюсь, эт-та парник».
Реплики лежат в объекте `SAY` в `js/game.js` — добавляются одной строкой.

Фоном живёт хозяйство: по парнику бродит и шарахается от хозяина курица, по соседскому полю
ползёт трактор «Беларус», из-за стекла машет Петрович со своими комментариями, в углу стоят
ванна, покрышка с цветами, батарея банок под закрутку и приёмник на табуретке.

## Управление

- `WASD` / стрелки — ходить
- `E` — полить · собрать · собрать жуков · набрать жижи · развести купорос · форточка · присесть · выпить
- `F` — опрыскать купоросом (куст и соседей)
- `1` – `4` — пустить в дело находку из карманов
- `P` / `Esc` — перекур (пауза), `M` — звук

На телефоне — экранный джойстик и две кнопки.

## Запуск локально

```bash
npx serve .
```

или просто открыть `index.html` в браузере.

## Деплой

```bash
npx wrangler pages deploy . --project-name=pomidory-minsk
```

## Структура

```
index.html      экран, меню, финальный экран
css/style.css   оформление меню и мобильных кнопок
js/game.js      состояние, ввод, климат, растения, фитофтора, действия, баланс
js/draw.js      отрисовка парника, кустов, огородника и интерфейса + главный цикл
```

Весь баланс — константами в начале `js/game.js`: `RUN_TIME`, `GOAL`, `BUCKET_MAX`,
`SPRAY_MAX`, `HANDS_MAX`, `SPEED`, `ACT`.
