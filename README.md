# 🍅 Помидоры под Минском

Браузерная аркада про огородника: парник, жижа, фитофтора, жара и градус в организме.
Чистый HTML/Canvas/JS — без сборки, без зависимостей, без картинок (вся графика рисуется кодом).

## Суть

Ты — лысый колхозник чуть за 40. Смена — 5 минут. Задача: сдать в ящик **24 спелых
неповреждённых** помидора. Мешает всё сразу:

| Что | Как работает |
|---|---|
| 💩 **Жижа** | поливаешь — куст растёт и завязывает плоды, но влажность в парнике растёт |
| 🦠 **Фитофтора** | споры прилетают из влажного воздуха и через открытые форточки; заражённый куст портит плоды, запущенный — сгорает |
| 💧 **Купорос** | сбивает заразу и даёт иммунитет на 16 сек, но 4 сек после обработки куст трогать нельзя |
| 🪟 **Форточки** | сушат и холодят парник, зато с соседской картошки задувает споры |
| 🥃 **Градус** | это силы. Тратится сам, на жаре — вдвое быстрее. Упал в ноль — ноги не идут. Перебрал — шатает и роняешь |
| ⏳ **Перезрев** | спелый помидор висит недолго: не сорвёшь — упадёт |

Ящик далеко слева, бочка, купорос и НЗ — справа. В руках больше пяти помидоров не унесёшь.
Каждые полминуты что-нибудь случается: печёт солнце, идёт дождь по крыше, сосед копает картошку.

## Управление

- `WASD` / стрелки — ходить
- `E` — полить · собрать · набрать жижи · развести купорос · открыть форточку · выпить
- `F` — опрыскать купоросом (куст и соседей)
- `M` — звук

На телефоне — экранный джойстик и две кнопки.

## Запуск локально

```bash
npx serve .
```

или просто открыть `index.html` в браузере.

## Деплой

```bash
npx wrangler pages deploy . --project-name=pomidory-minsk
```

## Структура

```
index.html      экран, меню, финальный экран
css/style.css   оформление меню и мобильных кнопок
js/game.js      состояние, ввод, климат, растения, фитофтора, действия, баланс
js/draw.js      отрисовка парника, кустов, огородника и интерфейса + главный цикл
```

Весь баланс — константами в начале `js/game.js`: `RUN_TIME`, `GOAL`, `BUCKET_MAX`,
`SPRAY_MAX`, `HANDS_MAX`, `SPEED`, `ACT`.
